# Навчальна структура автотестів

- `ui/` — сценарії та перевірки.
- `pages/` — майбутні класи сторінок.
- `components/` — майбутні класи спільних компонентів.
- `fixtures/` — майбутня підготовка об’єктів для тестів.
- `data/` — майбутні тестові дані.

Нові TypeScript-файли порожні. Наповнюємо їх разом з учнем по одному кроку.
`ui/store.spec.ts` — початковий тест, який учень уже запустив.
