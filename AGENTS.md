# QA Commerce Automation Lab

Це навчальний магазин на Medusa 2.17.2 та Next.js 15.5.18. Основний запуск — `npm run dev`; він піднімає PostgreSQL через Docker. `db:setup` змінює дані: міграції та seed. `infra:reset` видаляє volume з даними; не застосовуй як звичайний спосіб виправлення запуску.

UI-тести: `npx playwright test`; перелік без запуску сервісів: `npx playwright test --list`. Поточний `npm test` викликає Turbo, але в workspaces немає `test`-скриптів. Не звітуй про перевірені тести на підставі цієї команди. Jest-конфігурація посилається на відсутній `integration-tests/setup.js`.

Для навчального заняття застосуй `.agents/skills/qa-mentor/SKILL.md`, прочитай `docs/learning/progress.md` і потрібний розділ `docs/learning/plan.md`. Для проєктних питань використай `docs/learning/project-review.md` як початкову карту, потім перевір актуальний код. Документований стан не замінює виконані перевірки.

Розрізняй готовий код платформи, внесок учня і допомогу AI. Результат AI не доводить засвоєння матеріалу. Не позначай навичку підтвердженою без виконаної учнем роботи. Надавай джерела для актуальних рекомендацій щодо інструментів. Не показуй значення локальних env, токенів і cookies.

Якщо користувач прямо просить реалізацію, аудит або виправлення, виконуй роботу; навчальний формат не скасовує такого прохання. Не змінюй робочі дані Medusa через навчальні SQL-завдання: для DDL/DML потрібна окрема `qa_sql_lab`. Вона ще не створена.
