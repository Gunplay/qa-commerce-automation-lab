# Навчання Web QA на Medusa

Мета — перенести досвід ручного Desktop QA на web, API та дані, а потім навчитися підтримувати невелику автоматизацію з перевіреним використанням AI. Практична база — цей магазин; час — 1–2 години на тиждень.

## З чого почати

1. [Програма](plan.md): модулі, вправи та критерії засвоєння.
2. [Прогрес](progress.md): поточна точка й наступне завдання.
3. [Аналіз проєкту](project-review.md): архітектура, ризики та черга технічних робіт.
4. [AI, skills і MCP](ai-tools.md): вибір інструментів і практичне застосування.
5. [Перше заняття](lesson-01.md): карта системи та перша діагностика рівня.
6. [Excel-прогрес автоматизації](artifacts/site-automation-plan.xlsx): основний трекер — 39 критичних перевірок, по 3–4 на розділ; починай із вкладки «00 Прогрес». Статус покриття, останній запуск і доказ ведемо в цьому файлі.
7. [Ідеї Claude Code для навчання QA з Codex](claude-code-for-qa.md): пояснення термінів, приклади запитів, критерії review і план застосування до нашого проєкту.
   [Версія Word](artifacts/claude-code-for-qa.docx) з повним текстом, покроковою практикою, словником і списком підготовки.
8. [GitHub Actions і наш workflow Playwright](github-actions-guide.md): основи CI, три візуальні схеми, пояснення кожного рядка нашого YAML, командні сценарії PR, нічної регресії та випуску, діагностика й самоперевірка. Почни з розділу «Як вивчати».

## Як почати заняття з ментором

Відкрий саме `qa-commerce-automation-lab` як проєкт у Codex і почни нову сесію після додавання інструкцій. Скажи:

> Застосуй $qa-mentor. Прочитай docs/learning/progress.md. У мене 45 хвилин. Проведи наступне заняття, спочатку коротко перевір передумови. Повне рішення вправи дай після моєї спроби.

Якщо skill не відображається, попроси прочитати `.agents/skills/qa-mentor/SKILL.md` і провести заняття за ним. Це використання інструкцій за шляхом, а не підтвердження автоматичного завантаження skill.

Для перевірки налаштування попроси агента назвати прочитані файли, наступне завдання і бюджет часу. Очікується посилання на цей каталог, 1–2 години на тиждень і відсутність заяв про вже освоєні web/API-навички.

Це персоналізована конфігурація наявного AI-агента. Окремий бот, API-сервіс та автоматичне стеження за прогресом не створюються. Прогрес переноситься між сесіями через файл, коли агент читає й оновлює його. Навчальні документи підготовлені для репозиторію; MCP ще не підключено, SQL-лабораторію ще не створено.
